# AI Health Assistant

An end-to-end machine learning application that predicts diabetes risk from patient health data. Built with XGBoost for prediction and SHAP for explainability, with an interactive Streamlit UI that generates downloadable PDF reports.

---

## Features

- **Diabetes risk prediction** using an XGBoost classifier trained on the Pima Indians Diabetes Dataset
- **SHAP explainability** — waterfall charts showing which features drove each prediction
- **Interactive UI** — adjust patient parameters via sliders and get instant results
- **PDF report export** — download a summary of inputs and prediction results

## Quickstart

### 1. Clone the repository

```bash
git clone https://github.com/CynthiaOketch/AI-Health-Assistant.git
cd AI-Health-Assistant
```

### 2. Run setup

```bash
bash setup.sh
```

This creates a virtual environment, installs all dependencies, and trains the model.

### 3. Launch the app

```bash
venv/bin/streamlit run app/app.py
```

Then open **http://localhost:8501** in your browser.

## Manual Setup

If you prefer to set up step by step:

```bash
# Create and activate virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Train and save the model
python train_and_save.py

# Run the app
streamlit run app/app.py
```

## Dataset

The [Pima Indians Diabetes Dataset](https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database) contains diagnostic measurements for 768 female patients. The target variable (`Outcome`) indicates whether the patient has diabetes (1) or not (0).

| Feature | Description |
|---|---|
| Pregnancies | Number of pregnancies |
| Glucose | Plasma glucose concentration (2-hour oral glucose tolerance test) |
| BloodPressure | Diastolic blood pressure (mm Hg) |
| SkinThickness | Triceps skin fold thickness (mm) |
| Insulin | 2-hour serum insulin (mu U/ml) |
| BMI | Body mass index (kg/m²) |
| DiabetesPedigreeFunction | Diabetes pedigree function (genetic risk score) |
| Age | Age in years |
